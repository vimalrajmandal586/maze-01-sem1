01 / THE STORYEND OF SEMESTER ONE ↗

A final project that
actually moves.

Semester one gave me the basics: structure with HTML, styling with CSS, interactivity with JavaScript and jQuery, plus the first steps into Python, NumPy, C++ and object-oriented thinking.

Instead of putting those topics into another static “about me” page, I wanted something you could try. This maze is the browser part; the repo also has a small C++ solver and a Python/NumPy run analyzer.
